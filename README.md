# Placement Predictor

A machine-learning project that uses a student's CGPA and IQ to predict whether they will be placed.

## My Learning

I built this project to gain **hands-on** experience with the machine-learning workflow and take a step toward building end-to-end projects.

Through this project, I practiced:
- Preparing data and training a prediction model.
- Making predictions using CGPA and IQ.
- Saving the trained model with Python's pickle module.
- Organizing and sharing my work on GitHub.

## Repository Structure

    ├── PlacePredModel.pkl        # Saved trained model
    ├── PlacementPredictor.ipynb   # Project notebook
    ├──README.md                 # Project overview
    └── placement.csv            # dataset

## Explore the Project

Open `PlacementPredictor.ipynb` in Google Colab or Jupyter Notebook to follow the implementation.
